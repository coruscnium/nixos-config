# NixOS — ASUS ProArt PX13 (HN7306WU)

Flake-based system config. Hostname: `nixos`. Target: NixOS 26.05 + CachyOS kernel, Limine boot, ASUS/NVIDIA hybrid tuning.

## Layout
- `flake.nix` — inputs (nixpkgs 26.05, nix-cachyos-kernel) and the `nixos` host.
- `hardware-configuration.nix` — generated by `nixos-generate-config`, do not hand-edit.
- `modules/` — one concern per file: `nix`, `boot` (Limine), `kernel` (CachyOS), `hardware`, `nvidia`, `asus`, `desktop`, `networking`, `power`, `packages`.

## Apply
Run from this directory, or use absolute paths. Root is required.

    # build only — catches eval/build errors, changes nothing
    nixos-rebuild build --flake /home/coru/Projects/nixos-config#nixos

    # activate for this boot only (reverts on reboot) — good for a first try
    sudo nixos-rebuild test --flake /home/coru/Projects/nixos-config#nixos

    # make it the default
    sudo nixos-rebuild switch --flake /home/coru/Projects/nixos-config#nixos

Optionally move it to the conventional location and use it from there:

    sudo cp -r /home/coru/Projects/nixos-config /etc/nixos
    sudo nixos-rebuild switch --flake /etc/nixos#nixos

## Rollback
    sudo nixos-rebuild switch --rollback
    # or pick an older generation from the Limine menu at boot

## Notes
- First `switch` installs Limine to the ESP. The existing systemd-boot entry is
  left in place until Limine is confirmed booting.
- The CachyOS kernel is served by the lantian/attic binary cache; a first build
  may still take a while for the NVIDIA userspace modules.
